About Shinobi

Quiet tools for
loud ideas.

Shinobi is a small, friendly blog built to learn by doing. It is plain HTML, Bootstrap and a little JavaScript, with every post kept in a single JSON file. No frameworks, no build step and nothing to hide.

Everything you need to write, keep and show off a handful of posts, and nothing you don't.

Write freely

Plain storage

Light or dark

Bootstrap tour

How it works

A single Express server hands out the pages and a small REST API. The browser does the rest: it fetches posts, renders them as cards and sends your changes back.

It is deliberately small, so you can read the whole thing in an afternoon and change it with confidence.
